# Phông chữ phụ đề

Các phông trong thư mục này đều hỗ trợ đầy đủ tiếng Việt và được phát hành theo giấy phép
SIL Open Font License 1.1 (xem thư mục `LICENSES/`). Chúng được lấy nguyên bản từ kho
[Google Fonts](https://github.com/google/fonts), không chỉnh sửa.

## Thêm phông của riêng bạn

Chép tệp `.ttf` hoặc `.otf` vào thư mục `data/fonts/` (tạo nếu chưa có) rồi tải lại trang.
Phông sẽ xuất hiện trong danh sách chọn phông. Hãy dùng phông có đủ dấu tiếng Việt.
